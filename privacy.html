Privacy Policy

Klip Kilat runs only on the owner's computer. Login is done through the official TikTok and Google pages; passwords never pass through Klip Kilat.

Access tokens and basic profile info (name, avatar, account ID) are stored only in a local file on that computer, used only to post videos the user chooses, and never shared with third parties.

Users can delete their data by disconnecting the account in the app or revoking access in TikTok/Google settings.
